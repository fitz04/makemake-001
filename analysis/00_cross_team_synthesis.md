**참여:** 게임 디자이너, 테크 아키텍트, 내러티브 디자이너

## 핵심 결정 사항 (Decision Required)

### 1. 기술 스택: Godot 4.6 + Zylann VoxelTools (Double Precision) ✅ 합의

**세 에이전트 모두 동의.** 근거:
- 복셀 지형 필수 (채굴, 동굴, 구형 행성)
- VoxelTools가 유일한 통합 솔루션 (Unity는 자체 엔진 개발 6-12개월)
- solar_system_demo 레퍼런스 코드 존재
- 개발자 기존 리서치와 일치
- 무료(MIT), 빠른 이터레이션

**조건:** 초기 2주 프로토타입으로 800km 스케일 검증 필수
- 실패 시 대안: 스케일 다운 (80km → 20km) 또는 플레이어블 영역 제한

### 2. 추가설정노트의 지위 확정 ❗ 최우선

**게임 디자이너가 발견한 가장 심각한 문제.** GDD V10, 추가설정노트 20251228, 20251229가 동일 시스템(발전기, 로버, Act 1 범위)에 대해 3가지 다른 설계를 제시.

**권고안:**
- 추가설정노트의 과염소산염 + 질소 팽창 시스템을 채택 (환경 일관성)
- GDD V10의 세라믹 소결 + 원심 주조 퀘스트는 유지 (산화제만 교체)
- **GDD V11 통합 문서 작성이 구현 전 필수**

### 3. 행성 규모 결정 ❗ 프로토타입 후 결정

| 규모 | 장점 | 단점 |
|------|------|------|
| 800km (GDD 원안) | 서사적 임팩트, 매스드라이버 2500km 가능 | 미검증, 성능 리스크 |
| 80km (10배 축소) | 안전, 데모 범위 내 | 매스드라이버 250km로 축소 |
| 20km (solar_system_demo) | 검증 완료 | 게임플레이 영향 큼 |

**합의:** 2주 프로토타입에서 400km 반경 테스트 → 결과에 따라 결정

### 4. MVP 범위 확정 ✅ 합의

**핵심 루프:** 자원 채굴 → 제련 → 제작 → 전력 증가 → 자동화 → 반복

**MVP 포함:**
- Act 1-4 + 매스 드라이버 엔딩 1개
- 전력 4단계 (RTG → 메탄 → 이중화 → D-D)
- 프린터 3단계 (Mk.0 → Mk.1 → Mk.2)
- AI 케이 핵심 대사 + 감정 비트
- 복셀 지형 + 채굴 + 건설
- 후처리 파이프라인 (분위기 형성)

**MVP 제외 (후속 업데이트/DLC):**
- 엔딩 2 (뮤온 촉매)
- D-1 드론
- 식품 Tier 2.5 (튀긴 칩), Tier 3 (숙성 치즈)
- 하드 모드
- Living Lode 공생 차폐재
- 정전기 폭풍 이벤트

**예상 플레이 시간:** 15-20시간

### 5. 프로토타입 우선순위 ✅ 합의

**1단계 (2주):** 지형 + 분위기 프로토타입
- Godot Double Precision 빌드 + VoxelTools 세팅
- 구형 행성 생성 + 톨린 텍스처
- 후처리 파이프라인 (진공 그림자, 색보정, 블룸)
- 스케일 검증 (400km 반경 테스트)

**2단계 (2주):** 핵심 루프 프로토타입
- 1인칭 이동 + 저중력 물리
- 복셀 채굴 (edit_box)
- 기본 인벤토리 + 제작
- RTG → 메탄 발전기 전력 전환

## 에이전트 간 주요 토론 포인트 종합

### A. 문서 불일치 (14건 발견)

| 심각도 | 건수 | 핵심 사항 |
|--------|------|----------|
| Critical | 3 | 발전기 3중 설계, D-D 출력 10GW/2.1GW, 레이저 채굴 전력 |
| Major | 3 | R-1 로버, Act 1 범위, 10GW DD 융합로 잔재 |
| Minor | 8 | RTG 반감기, Z-Pinch, 부산물, Mk.1 방식 등 |

→ **V11 작성 시 전부 해소 필요**

### B. Act 3 과밀 + 감정 침체 문제

- 게임 디자이너: "8개 Phase가 5-7시간에 과밀, Act 3A/3B 분리 제안"
- 내러티브 디자이너: "5-7시간 감정 저지대, 마이크로 서사 + 중간 위기 삽입 필요"

**합의:** Act 3에 서사적 위기 1-2개 삽입 (예: 기계 고장, 케이의 위기)

### C. AI 케이 설계 보강

- 캐릭터 시트 공식 작성 필요 (성격 5개, 말투 가이드, 감정 트리거)
- "주인님" 호칭의 Act별 점진적 변화 → 관계 발전 서사 도구
- 사기 수치 연동 대사 시스템
- 자동화 완성 시 케이의 감정적 인정 대사 추가

### D. 엔딩 선택의 무게감

- 현재: 정보적 선택 ("어느 것이 효율적인가?")
- 목표: 가치적 선택 ("당신은 어떤 사람인가?")
- 방법: 각 엔딩에 비용(Cost) 부여, 케이의 의견 표명, 시간 제한

### E. 비주얼 분위기 파이프라인

테크 아키텍트 + 내러티브 디자이너 합의:

```
Act별 색상 팔레트:
Act 1: 청회색 + 비상등 빨강 (위기)
Act 2: 청회색 + 화덕 주황 + 녹조류 초록 (생명의 기운)
Act 3: 따뜻한 주황 + 산업적 노랑 (집이 되는 과정)
Act 4: 깊은 남색 + Living Lode 청백색 (경외)
```

후처리 연동:
- 사기 → 채도/렌즈 플레어
- 산소 → 비네트
- Living Lode 근접 → 색수차

### F. 사운드 디자인 방향

"진공은 침묵이 아니다" 원칙:
- 외부: 호흡, 심장박동, 도구 진동만
- 내부: 생명유지 장치 윙윙, 기계 소음
- 음악: Act 4 생존 완료 선언까지 없음 → 음악 자체가 서사적 보상
- 케이 음질: Act별 점진적 향상 (불안정→깨끗→따뜻→감정적 떨림)
