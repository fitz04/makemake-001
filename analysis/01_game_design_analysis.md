## 1. 메카닉 일관성 검증

### 1.1 문서 간 주요 불일치/모순 목록

#### [Critical] 발전기 설계 - 원본 GDD vs 추가설정노트 간 근본적 충돌

| 항목 | GDD V10 (마스터 비전 + 백과사전 + Journey) | 추가설정노트 20251228 | 추가설정노트 20251229 |
|------|-------------------------------------------|----------------------|----------------------|
| **Tier 1 명칭** | 메탄 발전기 (소결 세라믹 연소실 + 펠턴 휠 터빈) | 메탄 복합 사이클 발전기 (과염소산마그네슘 산화제 방식) | 질소 팽창 발전기 + 메탄 발전기 |
| **Tier 1 출력** | 50kW | 50kW + 난방열 10kW | 질소: 3.5kW / 메탄: 미명시 |
| **산화제** | 사바티에 반응 CO2 + 전해조 O2 | 과염소산마그네슘 Mg(ClO4)2 (외부 산소 불필요) | 과염소산염 (NaCl 부산물) |
| **부산물** | 없음 (혹은 CO2/H2O) | 염화마그네슘 슬래그 (MgCl2) | 소금 슬래그 (NaCl) |
| **연소실 재료** | 소결 세라믹 벽돌 (규사 SiO2 → 800-1000도 소결) | 명시 없음 (자가 기화 시스템) | 흙벽돌 화덕 |
| **핵심 퀘스트** | 소결 세라믹 → 원심 주조 터빈 날개 → 용접 조립 | 메탄 하이드레이트 + 과염소산마그네슘 채굴 | 질소 얼음 채굴 → "기관사" 노동 루프 |

**진단**: 이 세 문서는 Act 2의 핵심 루프를 서로 다른 방향으로 설계하고 있다. GDD V10은 "세라믹 소결 + 원심 주조"라는 정교한 공학 퀘스트 라인을 제시하고, 추가노트 20251228은 "과염소산염 산화제"라는 완전히 다른 화학 체계를 도입하며, 20251229는 "질소 팽창 엔진"이라는 새로운 Tier 0.5를 추가한다. 세 가지가 통합되지 않은 채 병존하고 있어, 실제 구현 시 어떤 설계를 따를지 결정이 필요하다.

**권고안**: 추가설정노트의 "과염소산염 + 질소 팽창" 시스템이 마케마케 환경(대기 없음, -230도)에 더 논리적으로 일관되므로, 이를 기반으로 GDD V11을 작성하되, V10의 세라믹 소결과 원심 주조 퀘스트 라인은 그대로 유지하고 산화제 공급 메커니즘만 교체하는 것을 권장한다.

|------|---------------|----------------|

### 1.2 [확인 필요] 사항 권고안

#### RTG 반감기 시스템

**현황**: Po-210 반감기 138일. V3(없음), V4(있음), V8(없음 제안) 간 미결정.
**권고안**: **기본 모드에서는 반감기 없음(1.5kW 고정), 하드 모드에서는 반감기 적용**을 권장한다.

이유:
- 반감기 138일은 게임 내 시간으로 매우 빠르게 감쇠한다. Act 2에서 메탄 발전기를 완성하기 전에 RTG가 0.7kW 이하로 떨어지면, Mk.0 프린터(1-2kW)조차 가동 불가능해져 데드락(진행 불가 상태)이 발생할 수 있다.
- 다만 하드 모드에서는 시간 압박이 핵심 긴장감이므로, RTG 감쇠가 "메탄 발전기를 빨리 만들어야 한다"는 동기를 강화한다.
- **하드 모드 적용 시 주의**: 데드락 방지를 위해 RTG 최소 출력 하한선(예: 0.5kW)을 설정하거나, AI '케이'가 비상 절전 모드를 제안하는 이벤트를 추가해야 한다.

#### Z-Pinch 역할

**현황**: "D-D 점화용? 주 융합로 점화용?" 미결정.
**권고안**: **D-D 비상 모드 점화용으로 확정**을 권장한다.

이유:
- 백과사전 1.4에서 "D-D 점화: Z-Pinch 1GW 필요"라고 명시.
- 주 융합로(D-He3)는 이미 파괴 상태이므로, "점화"가 아닌 "수리"가 필요하다.
- 게임플레이 흐름상, Z-Pinch 제작(Mk.2 프린터 필요) → D-D 점화(2.1GW 확보) → 융합로 수리 → 엔딩 분기로 이어지는 것이 자연스럽다.
- 단, Z-Pinch 자체가 1GW를 필요로 하는데, Act 3 종료 시점 전력이 ~200kW이므로 Z-Pinch를 어떻게 "점화"하는지에 대한 설명이 빠져 있다. 커패시터 뱅크 축적 등의 메커니즘 추가 필요.

#### 오리온 프로젝트 엔딩

**현황**: V3에서 엔딩 C로 포함 → V4/V8에서 제외 → 현재 미사용.
**권고안**: **완전 삭제를 권장**한다.

이유:
- 현재 2개 엔딩(매스 드라이버 / 뮤온 촉매)만으로도 충분한 선택의 깊이를 제공한다.
- 오리온 프로젝트(핵폭발 추진)는 AI 희생이라는 감정적 비용이 크지만, 매스 드라이버와 뮤온 촉매의 "불가능을 가능으로" / "생명과의 공생"이라는 주제적 대비에 비해 테마가 약하다.
- 솔로 개발 관점에서 3번째 엔딩은 리소스 낭비.

## 2. 전력 티어링 & 밸런스 분석

### 2.1 전력 곡선의 게임플레이적 타당성

```
전력 곡선 (로그 스케일):

Act 1    Act 2       Act 3         Act 4          엔딩
1.5kW    50kW       200kW        2.1GW         2.1GW
  |________|__________|____________|_____________|
  x33      x4         x10,500      x1

  생존      기반        최적화        완성          탈출
```

**분석**:

**Tier 0 → Tier 1 (1.5kW → 50kW, x33 배율)**: 가장 극적인 전환. "아무것도 없는 상태에서 최초의 산업 기반을 만든다"는 서사에 부합. 이 구간에서 플레이어는 금속 용융이 불가능하다는 제약(660도 필요)을 체감하고, 발전기 완성 시 해방감을 얻는다. **적절**.

**Tier 1 → Tier 2 (50kW → 200kW, x4 배율)**: 점진적 개선. 메탄 터빈 개량(100kW) + 수소 연료전지(50kW)로 이루어지는 이 구간은 "최적화"의 만족감을 제공하지만, **전력 증가 폭이 다른 티어 대비 상대적으로 작아 체감 임팩트가 약할 수 있다**. 대신 이 구간의 핵심은 "자동화 해금"이므로, 전력 수치보다는 로버/컨베이어 등의 시스템적 변화가 보상이 된다. **허용 가능하나, 200kW 달성 시 시각적/청각적 피드백 강화 필요**.

**Tier 2 → Tier 3 (200kW → 2.1GW, x10,500 배율)**: 폭발적 점프. "D-D 융합 점화"라는 단일 이벤트로 전력이 만 배 이상 증가한다. 이것은 게임 서사적으로 "생존 모드의 종료"를 의미하며 극도로 카타르시스적이다. **적절하나, 문제는 2.1GW를 활용할 콘텐츠가 엔딩 거대 건설에만 집중된다는 점**. 2.1GW 확보 후 엔딩 분기까지의 구간에서 전력이 남아도는 느낌이 들 수 있다.

**엔딩 구간 (2.1GW 유지)**: 매스 드라이버(2.1GW 직접 사용) / 뮤온 촉매(1.01GW 사용)로, 확보한 전력을 거대 프로젝트에 "쏟아붓는" 감각이 좋다. 다만 뮤온 촉매 루트는 2.1GW 중 1.01GW만 사용하므로 잉여 전력(1.09GW)의 활용처가 필요하다.

### 2.2 Act별 예상 플레이 시간과 콘텐츠 볼륨 균형

| Act | GDD 명시 플레이타임 | 게임 내 시간 | 핵심 콘텐츠 수 | 밀도 판정 |
|-----|-------------------|-------------|---------------|----------|
| Act 1 | 2-3시간 | 48시간 | 5대 위기 + Mk.0 프린터 | **적절** - 튜토리얼로서 과하지 않음 |
| Act 2 | 5-7시간 | 3-10일 | 발전기(3 난관) + 식량 + AI 광센서 + Mk.1 프린터 | **가장 밀도 높음** - 핵심 루프 학습 구간 |
| Act 3 | 5-7시간 | 10-20일 | 8개 Phase (채굴/전력/생산/식품/프린터/RTG/로봇/LL) | **과밀** - 8개 Phase를 5-7시간에 소화하기 어려움 |
| Act 4 | 3-5시간 | 20-30일 | 티타늄/텅스텐 + LL 연구 + D-D 점화 + 엔진 수리 | **얇음** - 전력 확보 후 반복 작업 위주 |
| 엔딩 | 미명시 | 1.4-2.3년 | 거대 건설 1개 | **미명시** - 가장 긴 게임 내 시간 대비 플레이 시간 불명 |

**핵심 우려사항**:

1. **Act 3가 과부하**: 8개 Phase를 5-7시간에 처리하는 것은 각 Phase당 약 40-50분인데, Phase 4(식품 자동화)의 치즈 숙성(30일)이나 Phase 6(RTG 제작)의 복잡성을 고려하면 시간이 부족하다. Act 3을 "Act 3A: 산업화" + "Act 3B: 자동화"로 분리하는 것을 제안한다.

2. **Act 4가 상대적으로 얇음**: 3-5시간 안에 티타늄 제련, 텅스텐 채굴, LL 연구, D-D 점화, 엔진 수리를 모두 진행하는데, 이 중 다수가 "재료 수급 → 제작"의 반복이다. Act 3에서 자동화를 완성했기 때문에 수동 작업이 적어지므로, 체감 플레이가 짧을 수 있다. 의도적이라면(자동화의 보상), 이를 서사적으로 보강할 필요가 있다.

3. **엔딩 구간의 플레이 시간 미정**: 1.4-2.3년의 게임 내 건설 시간을 실제 플레이 몇 시간으로 압축할 것인지 결정 필요. 건설 자동화가 고도화된 상태에서 "진행 바 관찰"만 되면 지루해진다.

### 2.3 사기/허기 시스템이 전체 진행에 미치는 영향

**허기 시스템**:
- 감소율 -5~-15/시간은 꽤 빠르다. 영양 페이스트(+10)를 4-6시간마다 제작 가능하다면, 평시(-5/시간)에 2시간마다 한 번은 먹어야 한다.
- Act 1에서 식량이 없는 상태로 시작하므로, Act 2의 MRE 오염 이벤트까지의 구간에서 어떻게 생존하는지 불분명하다. **Act 1에서 MRE를 소량 보유하고 시작하는 것인지 명시 필요**.
- 굶주림 상태(-50% 작업 속도)가 발전기 건설 퀘스트 중에 발생하면 악순환(느린 작업 → 더 오래 굶음 → 더 느린 작업)이 된다. 이는 의도적 긴장감인지 페널티 루프인지 설계 의도 확인 필요.

**사기 시스템**:
- [역겨움] 디버프의 중첩 메카닉은 매우 강력하다. 10스택 누적 시 [만성적 혐오](-15% 영구!)는 사실상 영구적 핸디캡이다.
- 치료제인 [기름에 튀긴 칩]은 Act 3 수준의 기술(피셔-트롭시 합성, 정밀 온도 제어)이 필요한데, [만성적 혐오]는 Act 2에서 발생할 수 있다. **Act 2에서 영구 디버프가 걸리면 Act 3까지 -15% 페널티를 안고 가야 한다**.
- 이것이 의도적이라면(자동화 동기 부여), [만성적 혐오]의 발생 조건을 더 완화하거나(20스택 등), Act 2 후반에 간이 치료 수단을 추가하는 것을 권장한다.
- 사기 0% 지속 시 게임 오버는 매우 가혹하다. "절망 이벤트" 같은 경고 시스템이 먼저 필요하다.

## 3. 플레이어 경험 곡선

### 3.1 각 Act의 감정 비트

```
감정 곡선 (개념도):

긴장 ▲                    ★D-D점화
     │  ★헬멧5분          │    ★엔딩선택
     │  │  ★MRE오염       │    │
     │  │  │              │    │     ★발사/공생
     │  │  │   ★AI시각    │    │     │
     │  │  │   │          │    │     │
해방 ─┤──┴──┴───┴──────────┴────┴─────┴──
     │     ★RTG ★발전기  ★자동화  ★수리완료
     │       ★셀레늄    ★치즈
     └──────────────────────────────────────→
      Act1    Act2       Act3     Act 4   엔딩
```

**Act 1 - "공포와 생존"**:
- 감정 아크: 공황 → 안도 → 호기심
- 5대 위기가 순차적으로 해결되면서 "한 고비 넘기기"의 리듬이 형성
- RTG 확보 + AI 재가동이 첫 번째 큰 안도감
- 잘 설계된 온보딩. **다만 5분 헬멧 타이머는 초보 플레이어에게 과도할 수 있음** - 사망 시 패널티를 경미하게(같은 지점 재시작) 설정해야 한다

**Act 2 - "장인의 고독"**:
- 감정 아크: 좌절(세라믹 실패) → 성취(발전기 완성) → 공포(MRE 오염) → 안도(식량 확보) → 감동(AI 시각)
- GDD 전체에서 **가장 감정 밀도가 높은 구간**
- AI '케이'의 "빛이... 보여요!" 이벤트는 게임 전체의 감정적 정점 중 하나
- 셀레늄 발견의 "와우 모먼트"가 공학적 탐구와 감정적 유대를 동시에 제공

**Act 3 - "공장장의 야망"**:
- 감정 아크: 답답함(수동 노동) → 해방(자동화) → 호기심(LL 발견) → 만족(치즈!)
- "귀찮음 → 자동화" 루프의 핵심 구간
- 치즈 완성은 의외로 강력한 감정 보상 (30일 숙성 기다림의 보상)
- **위험 요소**: Phase가 8개로 너무 많아 개별 성취감이 희석될 수 있음

**Act 4 - "귀환의 서막"**:
- 감정 아크: 결의 → 경외(D-D 점화) → 고민(엔딩 선택)
- AI의 "우리 이제... 죽지 않아요"가 심리적 전환점으로 매우 효과적
- D-D 점화(2.1GW)가 시각적/청각적으로 충분히 극적이어야 함

### 3.2 "귀찮음 → 자동화 → 해방감" 루프의 설계 효과

이 루프는 Factorio의 핵심 매력을 단일 플레이어 서사에 녹여낸 훌륭한 설계다.

**구체적 인스턴스**:
1. **질소 얼음 운반(기관사 노동)** → 컨베이어/로버 자동화 → 해방
2. **영양 페이스트 수동 제작** → 포름오스 반응기 자동화 → 해방 (+ 사기 문제는 여전)
3. **수동 채굴(핸드 드릴)** → 드릴 Mk.2 + 폭파 시스템 → 효율 10배
4. **수동 주조** → Mk.1 프린터 → Mk.2 프린터 (AI 완전 자동)

**효과 판정**: 매우 좋다. 다만 주의점이 있다:
- 자동화 이후에도 **플레이어가 해야 할 의미 있는 행동**이 남아야 한다. 모든 것이 자동화되면 "관리자 시뮬레이터"가 되어 몰입이 떨어진다.
- Act 3 후반~Act 4에서 플레이어의 직접 행동이 줄어드는 시점에 **탐험/발견(Living Lode 연구)이 새로운 주체적 행동**으로 작용하는 것은 좋은 설계다.

### 3.3 엔딩 2개의 선택 분기 동기 분석

**매스 드라이버 (물리적 탈출)**:
- 동기: "확실한 방법으로 집에 간다"
- 건설 규모: 2,500km 레일 (시각적 스케일이 압도적)
- 감정: 성취, 정복, 인류의 의지
- 건설 시간: 2.3년

**뮤온 촉매 (생명과의 공생)**:
- 동기: "생명체를 살리고 그 도움으로 귀환한다"
- 건설 규모: 10km 싱크로트론 (시각적으로 "하늘의 빛나는 고리")
- 감정: 경이, 연대, 우주적 외로움의 해소
- 건설 시간: 2.9년 (더 오래 걸림)

**분석**:
- 두 엔딩의 주제적 대비("정복 vs 공생")는 훌륭하다.
- **문제점 1**: 뮤온 촉매가 시간(2.9년 > 2.3년)도 더 걸리고 과학적으로 더 복잡한데, "합리적 선택"으로서의 매력이 부족하다. 왜 더 오래 걸리는 방법을 선택하는가? → **감정적 동기(생명체와의 유대, AI의 제안)**가 더 강해야 한다. Act 3의 Living Lode 첫 조우 이벤트를 강화하여, 플레이어가 생명체에 정서적 투자를 하도록 유도해야 한다.
- **문제점 2**: "선택 후 되돌릴 수 없음"이라고 하지만, 선택 시점에서 플레이어가 두 엔딩의 차이를 충분히 이해할 수 있는 정보가 제공되는지 불분명하다. AI '케이'가 각 방안의 장단점을 브리핑하는 장면이 필요하다.
- **문제점 3**: 두 엔딩 모두 "거대 건설 → 발사/귀환"으로 구조가 유사하다. 엔딩 경험의 차별화를 위해, 매스 드라이버는 "대규모 토목 공학"의 게임플레이(레일 섹션별 건설, 테스트 발사), 뮤온 촉매는 "생명체 관찰/양육"의 게임플레이(번식 모니터링, 동굴 탐험)로 질감 차이를 극대화해야 한다.

### 4.2 삭제/단순화해도 핵심이 유지되는 시스템

#### 즉시 단순화 가능

1. **D-1 드론 (스팀 추진)**: 로버만으로 물류 처리 가능. 드론은 "장거리 물류"라지만, 행성 직경 800km에서 50km 비행 범위는 제한적. 컨베이어 + 로버로 대체 가능. → **삭제하거나, 단순 텔레포트 물류(로딩 화면)로 대체**

2. **기름에 튀긴 칩 (Tier 2.5)**: 디버프 치료용 특수 아이템인데, 피셔-트롭시 합성 + 마이야르 반응 정밀 온도 제어는 별도 시스템이 필요. → **배양육 스테이크(Tier 2)에 치료 효과를 통합**

3. **정전기 폭풍 이벤트 (Terminator Event)**: 흥미로운 설정이지만 구현 비용(주기적 이벤트 + 슈퍼커패시터 + 접지 미니게임) 대비 게임플레이 임팩트가 작음. → **삭제하거나, 단순 "기상 이벤트" 경고로 축소**

4. **빙정석 합성 (하드 모드 Act 3)**: 5단계 화학 공정(형석 탐사 → 불산 제조 → 빙정석 합성 → 증류 정제)은 하드 모드 전용치고 너무 복잡. → **하드 모드에서도 채굴 가능하되 희귀도만 높이는 것으로 단순화**

5. **우주선 100톤 상세 스펙**: 구조재/시스템의 톤 단위 분류(기체 프레임 10톤, 추진 시스템 8톤 등)는 게임플레이에 직접 영향을 주지 않음. → **총 중량과 연료/추진제만 관리하는 것으로 단순화**

#### 단순화 검토 가능 (주의 필요)

6. **6족 보행 로버**: 6족 보행 애니메이션 + 저중력 물리는 구현 난이도가 매우 높음. → **4륜/6륜 구동으로 변경해도 핵심에 영향 없음**, 다만 시각적 개성이 약해짐

7. **pH 정밀 제어 치즈 제작**: 숙성 30일 + pH 4.6 자동 적정은 시뮬레이션 구현 비용이 높음. → **간소화된 "레시피 제작" 방식으로 대체 가능**, 다만 "공학적 식량" 테마가 약해짐

### 4.3 MVP에 반드시 포함해야 할 핵심 루프

```
[MVP 핵심 루프]

자원 채굴 → 제련/가공 → 제작 → 설치 → 전력 증가 → 더 나은 도구 → 반복
    ↑                                                          |
    └──────────────────────────────────────────────────────────┘

필수 요소:
1. 자원 채굴 (핸드 드릴 → 개량 드릴)
2. 제련 (전기로, 3단계 온도)
3. 프린터 (Mk.0 → Mk.1 → Mk.2)
4. 전력 (RTG → 메탄 발전기 → D-D 융합)
5. 생존 (산소 + 식량 + 사기)
6. AI 동반자 (대화 + 자동화 제어)
7. 1개 엔딩 (매스 드라이버 권장 - 시각적으로 더 직관적)
```

**MVP에서 제외 가능**:
- 엔딩 2 (뮤온 촉매) → DLC 또는 업데이트
- 드론 물류 시스템
- 식품 Tier 2.5 (튀긴 칩), Tier 3 (숙성 치즈)
- 하드 모드 전용 콘텐츠
- Living Lode 공생 시스템 (차폐재)
- 전력 이중화 (Tier 2) → 발전기 단순 업그레이드로 대체

**MVP 예상 콘텐츠 볼륨**: Act 1-4 + 매스 드라이버 엔딩 = 약 15-20시간

## 5. 토론 포인트 제안

### 5.1 테크 아키텍트와 논의해야 할 질문

1. **행성 규모 결정**: GDD는 직경 800km를 명시하나, 지형 전략 문서는 "20km+ 대규모 행성"을 전제로 한다. 실제 구현 행성 크기를 몇 km로 할 것인가? 800km를 스케일 다운(예: 80km)해도 게임플레이에 영향이 없는가?

2. **VoxelLODTerrain vs 프로시저럴 메시**: 복셀 기반 지형이 반드시 필요한가? 채굴/건설 시 지형 변형이 핵심이라면 복셀이 맞지만, "건물은 메시로"라는 하이브리드 전략을 이미 채택하고 있으므로, 지형 변형을 제한된 영역(채굴장, 기지 주변)으로 한정하고 나머지는 프로시저럴 메시로 처리할 수 있는지 검토.

3. **엔딩 거대 구조물의 기술적 실현 가능성**: 2,500km 매스 드라이버를 실시간 렌더링하는 것이 Godot 엔진에서 가능한가? 대안으로 "섹션별 건설 → 완성 시 사전 렌더링 컷신"이 현실적인지.

4. **시간 가속 시스템**: 게임 내 시간과 실제 시간의 비율, 시간 가속 기능의 범위(숙성 30일, 건설 27개월을 어떻게 처리할 것인가).

5. **세이브 시스템**: 복셀 지형 + 물류 자동화 상태 + AI 대화 진행도를 모두 포함하는 세이브 데이터의 크기와 로드 시간.

### 5.2 내러티브 디자이너와 논의해야 할 질문

1. **AI '케이'의 성격 깊이**: 현재 케이는 "순종적이고 다정한 도우미"로 그려지는데, 게임 전체(15-20시간)를 유일한 대화 상대로 견디려면 **갈등, 의견 충돌, 성장**이 필요하다. "케이가 Living Lode 채굴에 윤리적 반대를 표하는 장면" 등의 갈등 구조가 있는가?

2. **"살아있는 융합로" 생명체의 윤리적 딜레마**: 뮤온 촉매 엔딩에서 B종을 대량 번식시키는 것의 윤리적 의미를 플레이어에게 제기하는가? "에너지를 주고 연료를 받다"가 착취인지 공생인지에 대한 서사적 탐구가 필요하다.

3. **플레이어 캐릭터의 정체성**: 현재 플레이어 캐릭터에 대한 설정(이름, 배경, 동기)이 거의 없다. "무명의 아바타"로 갈 것인지, 고유한 캐릭터(예: 엔지니어 출신, 가족이 있는 사람)로 갈 것인지에 따라 엔딩의 감정적 무게가 달라진다.

4. **케이의 한국어/일본어 말투**: "주인님"이라는 호칭은 특정 문화적 뉘앙스를 가진다. 국제 시장을 고려할 때 이 호칭의 번역 전략은?

5. **"조난" 서사의 고립감**: 15-20시간 동안 AI 하나와만 대화하는 구조에서 플레이어의 고립감을 "게임의 장점"으로 활용할 것인지, "완화"할 것인지. 타이탄 게이트웨이와의 간헐적 통신 복구 같은 이벤트가 필요한지.

### 5.3 모든 에이전트가 함께 논의해야 할 질문

1. **MVP 범위 확정**: 위에서 제안한 MVP(Act 1-4 + 매스 드라이버)를 기준으로, 각 영역(테크/내러티브/디자인)에서 "반드시 필요한 것"과 "버릴 수 있는 것"의 합의.

2. **프로토타입 우선순위**: "지형 생성 + 포스트 프로세싱"이 개발자의 최우선 과제인데, 이것을 먼저 만든 후 게임플레이를 입힐 것인지, 게임 루프 프로토타입을 먼저 검증할 것인지.

3. **추가설정노트의 지위**: 20251228과 20251229의 설정이 GDD V10을 대체(supersede)하는 것인지, 후보안(proposal)인지 확정. 현재 세 문서가 병존하면서 가장 큰 혼란을 야기하고 있다.
